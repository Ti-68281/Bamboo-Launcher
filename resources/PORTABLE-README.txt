Bamboo 竹启动器 1.0.1（便携版）

启动：双击 Bamboo.exe
数据目录：%APPDATA%\Bamboo\data
缓存与日志：%APPDATA%\Bamboo\data\logs

说明：
1. 首次使用请先在账户面板创建离线账户，或配置 Azure 应用 ID 后登录 Microsoft。
2. Modrinth 无需密钥；CurseForge 需要在设置中填写自己的 API Key。
3. 离线皮肤使用本地 authlib-injector 桥接，首次启动需要联网下载约 300 KB 的 jar。
4. 便携版不写入注册表，删除文件夹即可卸载（游戏数据仍保留在 %APPDATA%）。
5. 便携版未做代码签名，Windows SmartScreen 可能提示“未知发布者”。

Bamboo 不收集遥测。Minecraft 是 Mojang Studios 的商标，本项目与 Mojang 无隶属关系。
