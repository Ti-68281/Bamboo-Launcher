# Bamboo v1.0.1

## 本次更新

- 重做侧栏展开 / 收起过渡：宽度、文字与图标分别缓动，收起时不再闪烁。
- 界面降噪：移除分组小标题、英文 overline 与重复说明，缩短页面标题和导航名称。
- 窗口控制按钮加粗、加大并补充悬停反馈，最小化 / 最大化 / 关闭更容易辨认。
- 启动过程改为竹节进度动画，显示检查、准备、启动三个阶段与实时百分比。
- 新增自动检查更新：读取 GitHub Releases、仓库 `package.json` 与官网版本信息，支持下载发布资产。
- 设置页右下角新增联系作者：`Ti68281@xbkjz.icu`、`xiaobao@xbkjz.cn`，点击即可复制。
- 版本号更新至 1.0.1。
- 可执行文件发布者信息更新为 `Ti68281`。

## 下载

- Windows x64 便携版：`Bamboo-Portable-1.0.1.zip`
- 解压后双击 `Bamboo.exe` 即可运行。

## 说明

便携版未进行代码签名，Windows SmartScreen 可能提示未知发布者。启动器数据默认保存在 `%APPDATA%\Bamboo\data`。
